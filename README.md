# อ่านไทย Translate Reader

อ่านหนังสือ/บทความภาษาอังกฤษ แล้ว **ดับเบิลคลิกคำ** หรือ **คลุมข้อความ** เพื่อแปลทันที
พร้อม **ความหมายในบริบทที่กำลังอ่าน**, **ตัวอย่างประโยคจากเหตุการณ์จริง**, **คำพ้องความหมายที่ใช้ง่าย**
และ **คลังคำศัพท์ส่วนตัว** ที่มีระบบทบทวนความจำ (spaced repetition) ให้คำที่เคยแปลไม่หลุดหายไปอีก

รองรับทั้งหน้าเว็บทั่วไป และ **ไฟล์ PDF ในเบราว์เซอร์** (มีตัวอ่าน PDF ในตัวที่เลือกข้อความได้) และมีตัวช่วยบน Windows
สำหรับเวลาอ่าน PDF ในโปรแกรมอื่น (Adobe Reader, Foxit, SumatraPDF, Word)

**ใช้บนมือถือ Android ได้ด้วย** — เป็นแอปที่ติดตั้งลงหน้าจอโฮมได้ แล้วใช้เมนู **แชร์** ของระบบส่งข้อความจากแอปไหนก็ได้เข้ามาแปล
ดูวิธีติดตั้งใน [`docs/MOBILE.md`](docs/MOBILE.md)

> ข้อมูลทุกอย่างเก็บอยู่ในเครื่องของคุณเท่านั้น — ไม่มีเซิร์ฟเวอร์กลาง ไม่มีบัญชีผู้ใช้ ไม่มีเก็บสถิติ

| อ่านแล้วจำไม่ได้ในระยะยาว | ระบบทบทวนแบบ spaced repetition พร้อมป้ายเตือนจำนวนคำที่ถึงกำหนด |

## ติดตั้ง (ส่วนขยาย)

ใช้ได้กับ **Chrome, Edge, Brave, Opera, Vivaldi** (เบราว์เซอร์ตระกูล Chromium) เวอร์ชัน 114 ขึ้นไป

1. เปิด `chrome://extensions` (Edge ใช้ `edge://extensions`)
2. เปิดสวิตช์ **โหมดนักพัฒนา / Developer mode** ที่มุมขวาบน
3. กด **โหลดส่วนขยายที่ยังไม่แพ็ก / Load unpacked**
4. เลือกโฟลเดอร์ **`extension`** ในโปรเจกต์นี้
5. หน้าตั้งค่าจะเปิดขึ้นอัตโนมัติ (ถ้าไม่ขึ้น ให้กดไอคอนส่วนขยายแล้วเลือก "ตั้งค่า")

หลังติดตั้งแล้ว **ให้รีเฟรชแท็บที่เปิดค้างไว้หนึ่งครั้ง** เพื่อให้ระบบเริ่มทำงานบนหน้านั้น

> ถ้าต้องการอ่าน PDF ที่เก็บไว้ในเครื่องด้วย (ไฟล์ `file:///...`) ต้องเปิดสิทธิ์เพิ่ม:
> `chrome://extensions` → การ์ดของส่วนขยาย → **รายละเอียด** → เปิด **อนุญาตให้เข้าถึง URL ของไฟล์**
> (หรือไม่ต้องเปิดก็ได้ — ใช้ปุ่ม "เปิดไฟล์" หรือลากไฟล์ PDF มาวางในหน้าตัวอ่านได้เลย)

## ใช้บนมือถือ Android

Chrome บนมือถือ **ติดตั้งส่วนขยายไม่ได้** จึงทำแอปเวอร์ชันมือถือแยกเป็น **PWA** ที่ติดตั้งลงหน้าจอโฮมได้
และใช้ **เมนูแชร์ของระบบ** เป็นทางเข้า — อ่านอะไรอยู่ก็ได้ เลือกข้อความ → แชร์ → อ่านไทย → ได้คำแปลทันที

```bash
npm run build:web     # ประกอบโฟลเดอร์ web/ (ต้องรันก่อนเสมอ)
npm run package       # ได้ dist/atthai-web-1.0.0.zip พร้อมอัปโหลด
npm run serve:web     # ทดสอบในเครื่องที่ http://localhost:8080
```

แล้วเอาโฟลเดอร์ `web/` ขึ้นโฮสต์ฟรีที่มี HTTPS

- **ถ้าโค้ดอยู่ใน GitHub แล้ว** (repo นี้): Settings → Pages → Source: **GitHub Actions** ครั้งเดียว
  workflow ที่เตรียมไว้จะประกอบและเผยแพร่ให้เองทุกครั้งที่ push → ได้ URL `https://ohojames.github.io/ai-translate/`
- **ถ้าอยากเร็วสุด**: ลากโฟลเดอร์ `web/` ไปวางที่ Netlify Drop → ได้ HTTPS URL ทันที

จากนั้นเปิดด้วย Chrome on Android → เมนู ⋮ → **ติดตั้งแอป**

รายละเอียดทั้งหมด (วิธีโฮสต์ทีละขั้น, วิธีใช้, ข้อต่างจากเวอร์ชันคอม, วิธีรวมคลังคำ, แก้ปัญหา)
อยู่ใน **[`docs/MOBILE.md`](docs/MOBILE.md)**

## ตัวอย่างที่ได้จากการค้นคำหนึ่งครั้ง

ค้นคำว่า `resilient` ในประโยค *"She lost her job twice, but she stayed resilient and kept applying."*

```
resilient                                              [adj.] [AI]
─────────────────────────────────────────────────────────────
ยืดหยุ่น
ความหมายตรงตัว: คืนตัวได้

ความหมายในบริบทนี้
  ในที่นี้หมายถึง "ไม่ยอมแพ้ ฟื้นตัวได้เร็วหลังเจอเรื่องร้าย" ไม่ได้หมายถึงวัตถุที่ยืดหยุ่น

🧠 ตัวช่วยจำ
  คิดถึงลูกบอลที่ถูกกดแล้วเด้งกลับทันที — resilient คือคนที่ "เด้งกลับ" ได้

คำแปลอื่นที่ใช้ได้
  ฟื้นตัวเร็ว — ใช้กับคน/ธุรกิจ
  ทนทาน     — ใช้กับวัสดุ

ความหมาย
  [adj.] กลับสู่สภาพเดิมได้เร็วหลังถูกกดหรือถูกทำร้าย (ใช้กับคน ระบบ หรือวัสดุ)

คำพ้อง · ง่าย/ใช้บ่อย
  [live สด] [elastic ยืดหยุ่น] [tough แข็งแกร่ง]
คำพ้อง · ทั่วไป
  [lively มีชีวิตชีวา] [springy ยืดหยุ่น]

ตัวอย่างการใช้ (เหตุการณ์จริง)
  ┌───────────────────────────────────────────┐
  │                     ประโยคที่คุณอ่าน        │
  │ She lost her job twice, but she stayed     │
  │ resilient and kept applying until she      │
  │ found something better.                    │
  │ เธอตกงานสองครั้ง แต่เธอยังคงไม่ยอมแพ้...     │
  └───────────────────────────────────────────┘
  ┌───────────────────────────────────────────┐
  │                              Tatoeba       │
  │ Children are often more resilient than     │
  │ adults think.                              │
  │ เด็ก ๆ มักยืดหยุ่นกว่าที่ผู้ใหญ่คิด         │
  └───────────────────────────────────────────┘

[บันทึกเข้าคลังคำ] [🔊] [📋] [AI อธิบาย]      google-free · 1.2s  [📚]
```

ข้อมูลแต่ละส่วนมาจากไหน:

| ส่วน | แหล่งข้อมูล (เมื่อไม่ใช้ AI) |
| --- | --- |
| คำแปล | Google Translate → Google Dictionary → MyMemory → LibreTranslate → DeepL (ไล่ตามลำดับที่ตั้งไว้) |
| ตัวอย่างจากบริบทที่อ่าน | ประโยคจริงที่คุณกำลังอ่าน (แปลไทยด้วยตัวแปล) |
| ตัวอย่างอื่น | Tatoeba (ประโยคจริงที่มีคนแปลไทยไว้แล้ว), Google, Wiktionary |
| คำพ้องที่ใช้ง่าย | Datamuse (จัดอันดับตามความถี่การใช้คำจริง) + Google |
| ความหมาย | Datamuse + Wiktionary (ภาษาอังกฤษ) |
| ชนิดคำ | Wiktionary / Google |
| อธิบายบริบท, ตัวช่วยจำ, ตัวอย่างแบบเหตุการณ์ | **AI** (ต้องเปิดใช้) |

## ตั้งค่า

เปิดได้จากไอคอนส่วนขยาย → ⚙ หรือคลิกขวาที่ไอคอน → "ตั้งค่าอ่านไทย"

- **ทั่วไป** — เปิด/ปิดส่วนขยาย, ธีม, ดับเบิลคลิก, ปุ่มลอย, ความกว้างการ์ด, เสียงอ่าน, เว็บที่ไม่ต้องทำงาน
- **การแปล** — ภาษาต้นทาง/ปลายทาง, เลือกลำดับผู้ให้บริการ + ปุ่มทดสอบทีละเจ้า, คีย์ของ LibreTranslate/DeepL, เวลาหมด
- **AI ช่วยอธิบาย** — เลือกเจ้า, โมเดล, API key, โหมด (เสริม/เป็นตัวหลัก), ปุ่มทดสอบ
- **ตัวอย่าง/คำพ้อง** — เปิด/ปิดแต่ละส่วน, จำนวนตัวอย่าง, กรองเฉพาะคำง่าย, เปิด/ปิด Tatoeba/Datamuse
- **PDF** — เปิด PDF อัตโนมัติ, ระดับซูมเริ่มต้น, จำหน้าที่อ่านค้าง, เว็บที่ไม่ต้องเปิดอัตโนมัติ
- **คลังคำศัพท์** — บันทึกอัตโนมัติเมื่อแปล, จำนวนคำต่อรอบทบทวน
- **ข้อมูล & สำรอง** — ส่งออก JSON/CSV, นำเข้า, ล้างแคช, คืนค่าตั้งต้น

## เปิดใช้ AI (ไม่บังคับ แต่แนะนำมาก)

AI คือส่วนที่ทำให้ได้ **ตัวอย่างเหตุการณ์จริง**, **ตัวช่วยจำ**, และ **คำแปลที่ตรงบริบทที่สุด**
ถ้าไม่เปิด AI ระบบยังใช้งานได้ครบ (แปล + คำพ้อง + ตัวอย่างจาก Tatoeba/บริบทที่อ่าน) แต่จะได้ข้อมูลเชิงลึกน้อยกว่า

เลือกเจ้าใดเจ้าหนึ่ง (ค่าใช้จ่ายต่อคำถูกมาก เพราะส่งข้อความสั้น ๆ):

| เจ้า | ตั้งค่า | หมายเหตุ |
| --- | --- | --- |
| **OpenAI** | provider `openai`, baseUrl `https://api.openai.com/v1`, model `gpt-4o-mini`, ใส่ API key | คุณภาพดี ราคาถูก |
| **OpenRouter** | provider `openai`, baseUrl `https://openrouter.ai/api/v1`, model เช่น `google/gemini-2.0-flash-001` | รวมหลายโมเดลในคีย์เดียว |
| **Google Gemini** | provider `gemini`, model `gemini-2.0-flash`, ใส่ API key | มีโควตาฟรี |
| **Anthropic Claude** | provider `anthropic`, model `claude-3-5-haiku-latest`, ใส่ API key | ภาษาไทยดี |
| **Ollama (ในเครื่อง)** | provider `ollama`, baseUrl `http://localhost:11434/v1`, model เช่น `llama3.1`, ไม่ต้องใส่คีย์ | **ฟรี 100%** ข้อมูลไม่ออกจากเครื่อง แต่ต้องรัน Ollama ไว้ |

กด **ทดสอบการเชื่อมต่อ AI** ในหน้าตั้งค่าเพื่อยืนยันว่าติดตั้งถูกต้อง

## อ่าน PDF

**วิธีที่ 1 — เปิดลิงก์ PDF บนเว็บ**
เมื่อเปิดไฟล์ `.pdf` เบราว์เซอร์จะพาไปหน้าตัวอ่านของส่วนขยายอัตโนมัติ (ปิดได้ในหน้าตั้งค่า → PDF)
ในตัวอ่านทำได้: เลือกข้อความ/ดับเบิลคลิกเพื่อแปล, 🌐 **แปลหน้านี้** (แปลทั้งหน้าเป็นไทย),
สารบัญ, ภาพย่อหน้า, ค้นหาในไฟล์, ซูม, หมุนหน้า, จำหน้าที่อ่านค้างไว้, ลากไฟล์มาวางเพื่อเปิด

**วิธีที่ 2 — ไฟล์ในเครื่อง**
กด **📂 เปิดไฟล์** ในตัวอ่าน หรือลากไฟล์ PDF มาวางในหน้าตัวอ่าน (วิธีนี้ไม่ต้องให้สิทธิ์อะไรเพิ่ม)

**วิธีที่ 3 — โปรแกรมอ่าน PDF นอกเบราว์เซอร์** → ใช้ [ตัวช่วยบน Windows](#ตัวช่วยบน-windows-สำหรับโปรแกรมอ่าน-pdf) ด้านล่าง

## ตัวช่วยบน Windows สำหรับโปรแกรมอ่าน PDF

สำหรับตอนอ่าน PDF ใน **Adobe Acrobat Reader, Foxit, SumatraPDF, Word** หรือโปรแกรมอื่น
ที่ส่วนขยายเบราว์เซอร์เข้าไปไม่ถึง — ตัวช่วยนี้ใช้คีย์ลัดระดับระบบ แล้วโชว์ป๊อปอัปแปลข้างเมาส์

```
desktop\Setup.bat          ← รันครั้งแรก เพื่อสร้างไฟล์ตั้งค่า
desktop\TranslateReader.bat ← ดับเบิลคลิกเพื่อเปิดใช้งาน (ทำงานเบื้องหลัง)
```

| คีย์ลัด | การทำงาน |
| --- | --- |
| `Ctrl` + `Alt` + `T` | คัดลอกข้อความที่เลือกอยู่ แปล แล้วโชว์ป๊อปอัป (คืนค่าคลิปบอร์ดเดิมให้อัตโนมัติ) |
| `Ctrl` + `Alt` + `Y` | แปลข้อความที่อยู่ในคลิปบอร์ดอยู่แล้ว (ไม่ส่ง Ctrl+C จึงไม่รบกวนโปรแกรมอื่น) |

ในป๊อปอัปมีปุ่ม ออกเสียง / บันทึก / คัดลอก / 🤖 AI อธิบาย
คำที่บันทึกจะเก็บที่ `%APPDATA%\AtThaiReader\vocabulary.json`
ซึ่ง **นำเข้าคลังคำศัพท์ของส่วนขยายได้** (หน้าตั้งค่า → ข้อมูล & สำรอง → นำเข้า JSON) เพื่อทบทวนรวมกัน

ตั้งค่าไฟล์ `%APPDATA%\AtThaiReader\config.json` เช่น

```json
{
  "targetLang": "th",
  "restoreClipboard": true,
  "hotkeyTranslate": "Ctrl+Alt+T",
  "hotkeyClipboard": "Ctrl+Alt+Y",
  "ai": {
    "enabled": true,
    "provider": "openai",
    "baseUrl": "http://localhost:11434/v1",
    "apiKey": "",
    "model": "llama3.1"
  }
}
```

อยากให้เปิดเองทุกครั้งที่บูตเครื่อง: กด `Win` + `R` → พิมพ์ `shell:startup` → สร้างชอร์ตคัตของ `TranslateReader.bat` วางไว้ในโฟลเดอร์นั้น

## คลังคำศัพท์และการทบทวน

- **บันทึกคำ** — กดปุ่มในการ์ด หรือ `Alt`+`S` หรือเปิด "บันทึกอัตโนมัติ" ในหน้าตั้งค่า
- **คลังคำศัพท์** — ค้นหา (คำ/คำแปล/บริบท/แท็ก), เรียงลำดับ, กรองแท็ก/ปักดาว/ถึงกำหนด,
  เพิ่มโน้ตของตัวเอง, แก้แท็ก, ดูบริบทเดิมและแหล่งที่มา, ออกเสียง, ลบ
- **ทบทวน** — บัตรคำแบบ spaced repetition (SM-2 แบบย่อ)
  กด `Space` เพื่อเฉลย แล้วให้คะแนน `1` อีกครั้ง · `2` ยาก · `3` ดี · `4` ง่าย (`S` = ข้าม)
  ระบบจะคำนวณวันทบทวนถัดไปให้เอง และขึ้นตัวเลขเตือนบนไอคอนส่วนขยาย
- **ส่งออก** — JSON (สำรอง/ย้ายเครื่อง) และ CSV (เปิดใน Excel หรือทำบัตรคำใน Anki)

## ความเป็นส่วนตัวและข้อมูล

- คำศัพท์, โน้ต, ประวัติ, แคชการแปล และ API key เก็บในเครื่องคุณเท่านั้น
  (`chrome.storage.local` และ IndexedDB — ไม่ซิงก์ขึ้นคลาวด์)
- เมื่อกดแปล ข้อความ (และประโยคบริบทโดยรอบ) จะถูกส่งไปยังผู้ให้บริการที่คุณเลือกเท่านั้น:
  Google Translate, MyMemory, LibreTranslate, DeepL และ/หรือ AI ที่คุณตั้งค่าไว้
- ระบบดึงข้อมูลพจนานุกรมเพิ่มเติมจาก Tatoeba, Datamuse และ Wiktionary (ส่งเฉพาะคำที่กำลังค้น ไม่มีข้อมูลส่วนตัว)
- ไม่มีการเก็บสถิติ ไม่มีการส่งข้อมูลไปที่อื่น และไม่มีการโฆษณา
- อยากให้ข้อมูลไม่ออกจากเครื่องเลย → ใช้ Ollama + LibreTranslate ที่รันในเครื่อง

## แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| ดับเบิลคลิกแล้วไม่มีอะไรขึ้น | รีเฟรชหน้าเว็บหนึ่งครั้ง · เช็คว่าไม่ได้ปิดส่วนขยายบนเว็บนั้น (ไอคอน → "เปิดบนเว็บไซต์นี้") · หน้า `chrome://` และ Chrome Web Store ถูกห้ามโดยตัวเบราว์เซอร์เอง |
| แปลไม่สำเร็จ / ขึ้น "บางแหล่งข้อมูลใช้ไม่ได้" | เปิดหน้าตั้งค่า → การแปล → กด **ทดสอบ** ทีละเจ้า แล้วจัดลำดับใหม่ (Google ฟรีบางเครือข่ายถูกจำกัดการใช้งาน) |
| คำแปลไม่ตรงบริบท | เปิดใช้ AI และตั้งโหมดเป็น "ให้ AI แปลเป็นตัวหลัก" |
| ไม่มีตัวอย่างประโยค | เปิด AI (ได้ตัวอย่างแบบเหตุการณ์จริง 2-4 ประโยค) หรือเปิด Tatoeba ในหน้าตั้งค่า |
| PDF เปิดในตัวอ่านไม่ได้ (ขึ้นกล่องแดง) | ไฟล์อาจต้องล็อกอินก่อน → เปิดแท็บเว็บนั้นให้ล็อกอิน แล้วเปิด PDF ซ้ำ · หรือกด "เลือกไฟล์จากเครื่อง" · หรือ "เปิดแบบปกติ" |
| เปิด PDF แล้วไม่เปลี่ยนไปตัวอ่าน | เช็คหน้าตั้งค่า → PDF → เปิดอัตโนมัติ · และดูว่าโดเมนนั้นอยู่ในรายการยกเว้นหรือไม่ |
| คีย์ลัด Alt+T ไม่ทำงาน | ไปตั้งใหม่ที่ `chrome://extensions/shortcuts` (อาจชนกับโปรแกรมอื่น) |
| ไม่ได้ยินเสียงอ่าน | ตรวจว่ามีเสียงใน Windows และเปิด `tts.enabled` ในหน้าตั้งค่า |
| AI ตอบช้า/ไม่ตอบ | ลด `maxTokens`, เพิ่ม `timeoutMs` หรือเปลี่ยนเป็นโมเดลที่เร็วกว่า (เช่น `gpt-4o-mini`, `gemini-2.0-flash`) |

## ข้อจำกัดที่ทราบ

- **PDF ที่เป็นภาพสแกน** ไม่มีชั้นข้อความ จึงเลือกคำไม่ได้ (ไม่มี OCR ในเวอร์ชันนี้) — ถ้าต้องการ แนะนำเปิด AI แล้วพิมพ์/วางข้อความเองในช่องค้นหาของป๊อปอัป
- **PDF ที่มีการป้องกัน (DRM/เข้ารหัส)** เปิดในตัวอ่านไม่ได้
- **PDF ที่ฝังอยู่ในหน้าเว็บ (iframe)** จะไม่ถูกเปลี่ยนไปตัวอ่านอัตโนมัติ (เปิดได้จากเมนูคลิกขวา)
- ใช้ได้เฉพาะเบราว์เซอร์ตระกูล Chromium (Chrome/Edge/Brave/Opera/Vivaldi) — ยังไม่รองรับ Firefox
- ตัวอ่าน PDF เน้นอ่านทีละหน้า ไม่ได้รองรับการพิมพ์/ฟอร์มใน PDF

## สำหรับนักพัฒนา

ไม่ต้องมีขั้นตอน build สำหรับส่วนขยาย — โหลดโฟลเดอร์ `extension` เข้าเบราว์เซอร์ได้ตรง ๆ (vanilla JS, ES modules)
ส่วนเว็บแอปมือถือมีขั้นตอน build เพราะประกอบจากต้นฉบับชุดเดียวกับส่วนขยาย

```bash
npm run check      # ตรวจ syntax ทุกไฟล์ (ส่วนขยาย + เว็บแอป + สคริปต์) และความถูกต้องของ manifest
npm run build:web  # ประกอบโฟลเดอร์ web/ จากต้นฉบับใน extension/src
npm run serve:web  # เซิร์ฟเวอร์ทดสอบที่ http://localhost:8080
npm run cors       # ตรวจว่า endpoint ใดเรียกได้จากหน้าเว็บ (เรื่อง CORS)
npm run smoke      # ยิง API จริงเพื่อทดสอบท่อการแปล (43 การทดสอบ)
npm run test-pdf   # สร้างไฟล์ PDF ตัวอย่างสำหรับทดสอบ
npm run e2e        # โหลดส่วนขยายเข้า Chromium จริงแล้วทดสอบการใช้งาน (31 การทดสอบ)
npm run e2e:web    # ทดสอบเว็บแอปบน Chromium โหมดมือถือ (43 การทดสอบ)
npm run verify     # รันทั้งหมดตามลำดับ
npm run icons      # สร้างไอคอนใหม่ (ทั้งของส่วนขยายและของแอปมือถือ)
npm run package    # แพ็ก ZIP ทั้งส่วนขยายและเว็บแอป (ไว้ที่ dist/)
```

ต้องติดตั้ง `playwright` (dev dependency) สำหรับ `npm run e2e` / `npm run e2e:web`
ถ้าเบราว์เซอร์ยังไม่มีให้รัน `npx playwright install chromium`

### นำโค้ดขึ้น GitHub (repo นี้เตรียมไว้ให้แล้ว)

remote ตั้งไว้ที่ `https://github.com/ohojames/ai-translate` และมีสคริปต์ที่ทำทุกอย่างให้ในคำสั่งเดียว
(ตรวจบัญชีของโทเคน → สร้าง repo ถ้ายังไม่มี → push → เปิด GitHub Pages → สั่งรัน workflow เผยแพร่แอปมือถือ)

```bash
GITHUB_TOKEN=<โทเคนของบัญชี ohojames> npm run push
```

ถ้าล็อกอิน gh ไว้หลายบัญชี ใช้แบบนี้ได้โดยไม่ต้องคัดลอกโทเคน:

```bash
gh auth login                                    # เข้าสู่ระบบเป็น ohojames (ทำครั้งเดียว)
GH_TOKEN=$(gh auth token --user ohojames) npm run push
```

บน PowerShell: `$env:GH_TOKEN = gh auth token --user ohojames; npm run push`

> **หมายเหตุของเครื่องนี้:** `git config` และ `gh` ตั้งไว้เป็นบัญชี `openlinkthailand-art`
> ซึ่งไม่มีสิทธิ์ใน repo ของ `ohojames` จึงต้องใช้โทเคน/การล็อกอินของ `ohojames` เท่านั้น
> โทเคนที่ต้องใช้: classic PAT สิทธิ์ `repo` หรือ fine-grained ที่ให้ Contents (Read and write),
> Administration (Read and write) และ Pages (Read and write)

หลัง push สำเร็จ แอปมือถือจะอยู่ที่ `https://ohojames.github.io/ai-translate/` (ใช้เวลาประกอบประมาณ 1 นาที)

โครงสร้างโปรเจกต์และสถาปัตยกรรมอยู่ใน [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
แผนการพัฒนาและสิ่งที่ทำแล้ว/ต่อไปอยู่ใน [`docs/PLAN.md`](docs/PLAN.md)
คู่มือมือถืออยู่ใน [`docs/MOBILE.md`](docs/MOBILE.md)

### เทคโนโลยีที่ใช้

- **pdf.js** (Apache-2.0) สำหรับตัวอ่าน PDF — ฝังไว้ใน `extension/vendor/pdfjs`
- **Tatoeba, Datamuse, Wiktionary, Google Translate, MyMemory** เป็นแหล่งข้อมูลคำแปล/ตัวอย่าง/คำพ้อง
- ไม่มี framework, ไม่มี build step, ไม่มี dependency ตอนรัน
